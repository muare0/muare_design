# 뮤아르 디자인 스튜디오 - 프로젝트 이관 가이드

## 📋 상황 정리

현재 프로젝트는 다음 세 곳에 있습니다:
- **GitHub**: 코드 저장소 (브라이언 계정)
- **Supabase**: 데이터베이스 (브라이언 계정)
- **Vercel**: 배포 (브라이언 계정)

이 가이드를 따라 여자친구 자신의 계정으로 모두 옮길 수 있습니다.

---

## ✅ 단계 1: GitHub에서 포크하기

### 1-1. 저장소 포크
1. GitHub에서 프로젝트 저장소 접속
2. 우측 상단 **Fork** 클릭
3. Owner는 자신의 계정으로 선택
4. **Create fork** 클릭

→ 이제 자신의 GitHub 계정에 `muare-design-studio` 저장소가 생깁니다

### 1-2. 로컬 컴퓨터에 받기
```bash
# 자신의 GitHub 사용자명을 넣으세요
git clone https://github.com/여자친구깃헙이름/muare-design-studio.git
cd muare-design-studio
```

---

## ✅ 단계 2: Supabase 준비 (새 프로젝트)

### 2-1. Supabase 회원가입/로그인
1. [supabase.com](https://supabase.com) 접속
2. 자신의 계정으로 로그인 (또는 가입)

### 2-2. 새 프로젝트 만들기
1. **New Project** 클릭
2. Project name: `muare-design-studio`
3. Region: **Northeast Asia (Seoul)** 선택
4. Database Password: 안전한 비밀번호 입력
5. **Create new project** 클릭
   
   (프로젝트 생성에 약 5-10분 소요)

### 2-3. 데이터베이스 초기 설정

프로젝트가 생성되면:

1. 왼쪽 메뉴 **SQL Editor** 클릭
2. **New query** → 다음 파일의 내용을 전체 복사해서 붙여넣기:
   - 파일: `supabase/schema.sql`
   
3. **RUN** 클릭 (테이블들이 생성됨)

4. 같은 방식으로 `supabase/seed.sql` 도 실행
   (현재 사이트의 기본 문구와 포트폴리오 예시가 들어갑니다)

### 2-4. 관리자 계정 생성

1. Supabase → **Authentication** → **Users**
2. **Add user** 클릭
3. 자신의 이메일 입력 + 비밀번호 설정
4. **Save** 클릭

그 다음 **SQL Editor** 에서 다음을 실행:

```sql
insert into public.admins (user_id, email)
select id, email from auth.users where email = '자신의이메일@gmail.com';
```

### 2-5. API 키 복사

1. Supabase → **Project Settings** → **API**
2. 다음 두 개를 복사해서 안전한 곳에 보관:
   - **Project URL** (예: `https://xxxxxxxxxxxxxxxx.supabase.co`)
   - **anon public** 키 (긴 문자열)

⚠️ **service_role 키는 절대 복사하지 마세요!**

## ✅ 단계 3: 로컬에서 환경 변수 설정

### 3-1. `.env` 파일 생성

프로젝트 폴더(`muare-design-studio`) 루트에서:

1. `notepad .env` 실행 (또는 VSCode에서 새 파일 만들기)
2. 다음 내용 입력:

```
VITE_SUPABASE_URL=https://xxxxxxxxxxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```

(위에서 복사한 값을 그대로 붙여넣으세요)

3. 저장 후 닫기

### 3-2. 로컬에서 테스트

```bash
npm install      # 처음 한 번만
npm run dev      # 실행 → http://localhost:5173
```

브라우저에서 `http://localhost:5173/admin` 접속
→ 로그인 화면이 나와야 합니다 (자신이 만든 이메일 + 비밀번호로 로그인 가능)

---

## ✅ 단계 4: Vercel에 배포

### 4-1. Vercel 회원가입/로그인
1. [vercel.com](https://vercel.com) 접속
2. 자신의 계정으로 로그인 (GitHub 계정으로 연결 권장)

### 4-2. 프로젝트 추가
1. **Add New** → **Project** 클릭
2. GitHub에서 `muare-design-studio` 저장소 선택
3. **Import** 클릭

### 4-3. 환경 변수 설정
1. **Environment Variables** 섹션에서:
   - `VITE_SUPABASE_URL` = (위에서 복사한 URL)
   - `VITE_SUPABASE_ANON_KEY` = (위에서 복사한 키)
2. 각각 입력 후 **Deploy** 클릭

(배포에 약 1-2분 소요)

### 4-4. 배포 확인
Vercel에서 제공하는 URL로 접속하면 사이트가 보입니다.

---

## ✅ 단계 5: 도메인 연결 (muare-design.com)

### 5-1. Vercel에서 도메인 연결

1. Vercel → **Settings** → **Domains**
2. **Add Domain** 클릭
3. `muare-design.com` 입력

### 5-2. DNS 레코드 추가

Vercel에서 안내하는 DNS 레코드를 도메인 구입처(가비아, 후이즈 등)의 관리자 화면에 추가하면 됩니다.

> 도메인 업체에 따라 적용까지 24시간까지 소요될 수 있습니다.

## ❓ 자주 묻는 질문

### Q1. 기존 포트폴리오 데이터는?
**A.** `supabase/seed.sql` 을 실행하면 기본 문구와 예시 6개 프로젝트가 들어갑니다.
더 이상 필요한 포트폴리오가 있으면 `/admin` 에서 새로 추가하세요.

### Q2. 브라이언의 Vercel/Supabase는 어떻게?
**A.** 이 가이드를 따르면 여자친구 자신의 계정에만 올라갑니다.
브라이언은 자신의 계정에서 별도로 관리할 수 있습니다.

### Q3. 로그인이 안 돼요
**A.** 다음을 확인하세요:
1. `.env` 파일이 제대로 저장되었는가
2. Supabase에서 관리자 계정을 만들었는가 (SQL 실행)
3. 로그인 이메일이 정확한가

### Q4. `/admin` 접속 시 403 에러
**A.** Supabase의 RLS(보안 규칙) 때문입니다.
다시 확인:
```sql
-- Supabase SQL Editor에서 실행
select * from public.admins;
```
자신의 이메일이 리스트에 있는지 확인하세요.
