# 뮤아르 디자인 스튜디오 - 프로젝트 넘겨받기 가이드

## 📌 상황 정리

현재 프로젝트는 여기에 있습니다:
- **코드 저장소**: GitHub (브라이언 계정)
- **데이터베이스**: Supabase (브라이언 계정)
- **배포된 사이트**: https://muare-design.vercel.app/ (브라이언 Vercel 계정)

이 가이드를 따라하면 **모든 것을 자신의 계정으로 옮길 수 있습니다.**

---

## 준비물 확인

시작하기 전에 다음을 준비하세요:

- 이메일 주소 1개 (가급적 Gmail 추천)
- 웹 브라우저 (Chrome, Edge, Safari 모두 OK)
- 약 30분의 시간

> **계정 3개를 새로 만들어야 합니다:** GitHub, Supabase, Vercel

---

# 🚀 5단계 이관 가이드

## 단계 1️⃣: 파일 받기 및 압축 풀기

### 1-1. 브라이언에게 폴더 받기
브라이언이 폴더를 **ZIP 파일로 압축**해서 보낼 겁니다.
- 파일명: `muare-design-studio.zip`

### 1-2. 압축 풀기
1. 받은 ZIP 파일 우클릭
2. **압축 풀기** (또는 **Extract All**)
3. 선택한 위치에서 풀리면 `muare-design-studio` 폴더가 생깁니다

> Windows는 ZIP을 우클릭 → 압축 풀기
> Mac은 더블클릭하면 자동 압축 해제

---

## 단계 2️⃣: GitHub 계정 만들고 코드 올리기

### 2-1. GitHub 가입

1. [github.com](https://github.com) 접속
2. 우측 상단 **Sign up** 클릭
3. 다음 정보 입력:
   - 이메일 주소
   - 비밀번호 (8자 이상, 문자+숫자 포함)
   - 사용자 이름 (아이디처럼 사용, 나중에 변경 가능)
4. 이메일 인증 완료

### 2-2. 새 저장소 만들기

로그인 후:

1. 우측 상단 프로필 → **Your repositories**
2. **New** 버튼 클릭
3. 다음 정보 입력:
   - Repository name: `muare-design-studio`
   - Description: `Muare Design Studio Website and Portfolio CMS` (선택사항)
   - Public 또는 Private 선택 (자유)
   - **Create repository** 클릭

### 2-3. 파일 올리기 (가장 쉬운 방법)

새로 만든 저장소 화면에서:

1. **Add file** 버튼 → **Upload files** 클릭
2. 파일 탐색기에서 압축 푼 폴더의 모든 파일을 선택
   - ⚠️ **`node_modules` 폴더는 업로드하지 마세요** (너무 크고, 나중에 자동 설치됨)
3. 모든 파일을 드래그 앤 드롭으로 업로드
4. 아래 **Commit changes** 클릭

> **폴더 구조 유지하기:**
> - `src/` 폴더 통째로 업로드
> - `public/` 폴더 통째로 업로드
> - `supabase/` 폴더 통째로 업로드
> - 루트의 모든 설정 파일 (package.json, vite.config.ts 등)

---

## 단계 3️⃣: Supabase 계정 만들고 데이터베이스 설정하기

### 3-1. Supabase 가입

1. [supabase.com](https://supabase.com) 접속
2. **Sign up** (이메일로 가입)
3. 이메일 인증 완료

### 3-2. 새 프로젝트 만들기

로그인 후:

1. **New project** 버튼 클릭
2. 정보 입력:
   - Project name: `muare-design-studio`
   - Database password: 안전한 비밀번호 (기억해두세요!)
   - Region: **Northeast Asia (Seoul)** 선택
3. **Create new project** 클릭

> 프로젝트가 준비되는 데 5-10분 소요됩니다. 잠깐 기다리세요.

### 3-3. 데이터베이스 구조 만들기

프로젝트 준비 완료 후:

1. **SQL Editor** 클릭 (왼쪽 메뉴)
2. **New query** 클릭
3. 브라이언이 제공한 `supabase/schema.sql` 파일을 열어서 **전체 내용 복사**
4. SQL Editor 창에 붙여넣기
5. **RUN** 버튼 클릭 (파란 버튼)

> 테이블들이 자동으로 생성됩니다.

### 3-4. 기본 데이터 넣기

같은 방식으로:

1. `supabase/seed.sql` 파일 내용 복사
2. SQL Editor에 붙여넣기
3. **RUN** 클릭

> 이제 홈페이지의 기본 글귀와 샘플 포트폴리오 6개가 들어갑니다.

### 3-5. 관리자 계정 만들기

이제 자신이 관리자임을 등록해야 합니다:

1. **Authentication** 클릭 (왼쪽 메뉴)
2. **Users** 탭
3. **Add user** 버튼
4. 자신의 이메일과 비밀번호 입력
5. **Save** 클릭

그 다음, SQL Editor로 돌아가서:

1. **New query** 클릭
2. 다음을 입력 (자신의 이메일을 넣으세요):

```sql
insert into public.admins (user_id, email)
select id, email from auth.users where email = '자신의이메일@gmail.com';
```

3. **RUN** 클릭

### 3-6. 중요한 키 복사해두기

나중에 필요하니까 어디선가 저장해두세요:

1. **Project Settings** 클릭 (왼쪽 아래)
2. **API** 탭
3. 다음 두 가지를 복사해서 노트에 저장:

```
Project URL: https://xxxxxxxxxxxxxxxx.supabase.co

Anon public key: (긴 문자열)
```

> ⚠️ `service_role` 키는 절대 복사하지 마세요. 위험합니다.

## 단계 4️⃣: 컴퓨터에서 테스트해보기

### 4-1. 필요한 프로그램 설치 (처음 1회만)

1. [Node.js](https://nodejs.org/) 사이트에서 **LTS 버전** 다운로드 및 설치
2. 설치 후 컴퓨터 재시작

### 4-2. 설정 파일 만들기

압축 푼 `muare-design-studio` 폴더에서:

1. 메모장 열기 (또는 VSCode)
2. 새 파일 만들기
3. 다음 입력 (위에서 복사한 값으로):

```
VITE_SUPABASE_URL=https://xxxxxxxxxxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```

4. 파일명: `.env` (점으로 시작)
5. 폴더 루트에 저장 (`muare-design-studio` 바로 아래)

### 4-3. 터미널에서 실행

Windows:
1. 폴더 빈 공간에서 우클릭
2. **터미널 열기** 선택

Mac:
1. 폴더를 드래그해서 터미널에 떨어뜨리기
2. 또는 터미널 앱에서 폴더 경로 입력

그 다음:

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 열기 → 홈페이지가 보이면 성공!

## 단계 5️⃣: Vercel에 배포하기

### 5-1. Vercel 가입

1. [vercel.com](https://vercel.com) 접속
2. **Sign up** → **GitHub 계정으로 로그인** 선택 (가장 간단)
3. 연결 완료

### 5-2. 배포 설정

1. **Add New** → **Project**
2. GitHub에서 `muare-design-studio` 저장소 선택
3. **Import** 클릭

### 5-3. 환경 변수 입력

**Environment Variables** 섹션:

1. **Add New → From .env** 클릭
2. 또는 직접 입력:
   - Name: `VITE_SUPABASE_URL`
   - Value: (위에서 복사한 URL)
3. **Add** 클릭
4. 같은 방식으로 `VITE_SUPABASE_ANON_KEY` 추가

### 5-4. 배포 시작

1. **Deploy** 버튼 클릭
2. 1-2분 기다리면 배포 완료!
3. Vercel에서 제공하는 URL로 접속 → 자신의 사이트가 보입니다

## ✅ 완성! 이제 뭘 할 수 있나요?

### 포트폴리오 추가하기

주소 뒤에 `/admin` 붙여서 접속:
- 로컬: `http://localhost:5173/admin`
- 배포 후: `https://yoursite.vercel.app/admin`

로그인 → **+ ADD PROJECT** → 포트폴리오 추가 가능

### 사이트 글귀 수정하기

`/admin` → **Content** 탭에서:
- 메인 문구
- 소개글
- 서비스 항목
- 연락처

모두 수정 가능합니다.

### 디자인 색상 바꾸기

`/admin` → **Design** 탭에서:
- 배경색
- 텍스트색
- 강조색

즉시 적용됩니다.

## ❓ 막히는 부분이 있으면?

| 상황 | 확인할 것 |
|------|---------|
| npm install 안 됨 | Node.js 제대로 설치됐는지 확인 |
| 로그인이 안 됨 | Supabase에서 **관리자 계정을 SQL로 등록**했는지 확인 |
| Vercel 배포 실패 | 환경 변수가 정확히 입력됐는지 확인 |
| 사이트가 안 보임 | Vercel 배포 로그 확인 (Vercel 대시보드 → Deployments) |
